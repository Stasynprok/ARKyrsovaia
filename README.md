# Заказ курсовой работы по AR на Unity.
## Задание
В качестве курсовой работы выбрана реализация игры doodle jump в среде AR.

Для игры должны быть созданы 2 уровня, каждый из которых будет запускаться при обнаружении соответствующего QR кода. В QR коде должен быть закодирован JSON файл уровня, который предварительно был записан при помощи скрипта в редакторе. При запуске уровня QR код является якорной точкой, при это уровень всегда обращен в сторону камеры.

Для управления персонажем должны использоваться кнопки на экране.

Для начала игры необходимо отсканировать QR код уровня, до тех пор, пока это не сделано, на экране отображается надпись «Считайте QR код». Когда QR код отсканирован начинается игра, поиск QR кодов прекращается. Когда уровень заканчивается, появляется надпись «Победа» и кнопка «Обнаружить новый уровень».
При нажатии на кнопку «Обнаружить новый уровень» запускается поиск QR кодов и появляется надпись «Считайте QR код».

При запуске уровня главный герой находится на платформе в центре экрана. При нажатии на экран он подпрыгивает. Если главный герой прыгает на платформу, он от нее отталкивается. В игре должна быть отчетливо видимая линия, при достижении которой любые игровые объекты уничтожаются.
Если главный герой будет уничтожен игра останавливается, появляется надпись «Игра окончена» и 2 кнопки: «Начать заново», при нажатии которой уровень будет запущен заново, и «Обнаружить новый уровень», при нажатии которой будет запущен поиск QR кодов и появляется надпись «Считайте QR код».

Игровой процесс состоит из постоянного отскакивания главного героя от платформ. После начала игры платформы идут сверху-вниз с определенной скоростью. Если при отскакивании от платформы игрок взлетает выше центра игрового поля, то он остается на середине игрового поля, а платформы ускоряют свое движение, пока у игрока не закончится подъемная сила, после чего замедляются до обычного состояния. 

В игре должно быть 3 вида платформ:\
•	Обычные – при попадании игрока на эту платформу он прыгает с обычной скоростью;\
•	Разрушаемые – при попадании игрока на эту платформу он прыгает с обычной скоростью, после чего платформа разрушается, и игрок больше не может с ней взаимодействовать;\
•	Ускоряющие – при попадании игрока на эту платформу он прыгает с удвоенной скоростью.

## Из интересного в реализации
Каждый уровень представлен отдельным префабом со скриптом формирующий JSON из положения платформ на уровне.

Для уменьшения количества символов float в JSON применяется окргление и запись в int. Уменьшение символов необходимо для вхождения в рамки максимально допустимого размера байт в QR.

Для определения местоположения QR кода в пространстве использовалось анкерное изображение в центре. Определяя заранее известное изображение устанавливается точка привязки локации в пространстве.

Для считывания QR кода была использована библиотека ZXing.NET.
